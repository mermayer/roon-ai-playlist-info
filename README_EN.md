# Roon AI Playlist

**Roon AI Playlist** extends an existing Roon system with additional tools for playback, playlists, live radio, audiobooks, personal listening statistics, and control of external devices.

The application connects to a Roon Core on the local network. It can be used as a complete Windows application, in a web browser, or through the lightweight **RoonAIViewer** Windows client.

> Roon AI Playlist is an independent project and is not affiliated with, endorsed by, or supported by Roon Labs, TIDAL, Last.fm, Deezer, fanart.tv, Audible, or any supported AI provider.

## Current versions

- Roon AI Playlist: **1.0.458**
- RoonAIViewer: **1.0.3**

## Highlights

- AI-assisted playlists with multiple selectable providers
- direct matching of suggested tracks against the Roon library
- enhanced zone views with artwork, artist images, queue, and remaining time
- enrichment of incomplete live-radio metadata and artwork
- audiobook management with chapters, progress, and bookmarks
- personal **Roon Wrapped** statistics with show, story, and exports
- management of missing covers and artist images
- configurable HTTP network triggers for external devices
- browser view for tablets, wall displays, and remote computers
- dedicated **RoonAIViewer** for Windows with tray operation, autostart, and securely stored connection details
